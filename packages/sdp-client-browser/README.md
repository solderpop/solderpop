# sdp-client-browser

This package is a part of the [SolderPop IDE](https://github.com/solderpop/solderpop) project.

The package is a thin wrapper around [`sdp-client`](https://github.com/solderpop/solderpop/tree/main/packages/sdp-client) which lifts it to a ready-to-use browser based SolderPop IDE.
